## About

**Financial Tracker** is  a lightweight, browser-based application on designed to help users manage their personal finances. It allows for the recording of income and expenses, provides a real-time overview of account balance, and offers a straightforward way to monitor financial habits - all without the need for a backend server or database.

This is personal project, built indepently to practice and improve front-end web development skills - not a school requirement or assignment.
